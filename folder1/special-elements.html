To create special-elements, we use & text ;

for example, we write & lt ; for < AND & gt ; for > (ga jelas di web, liat di html file nya)

to connect two words in a line when using space, use & nbsp ;

to create a dummytext quickly, use lorem + text amount

to create a linebreak, use <br>


to create a horizontal line, use <hr>
