POSITIONS

there are several positions an element can be positioned in:

Relative, to be positioned relative to where it normally is supposed to be

Fixed, to stay in the same place on the screen, good for screen headers and such

Absolute, to be placed in according to its closer ancestor (div parent), moving the parent div also moves the child div

Sticky, similar to fixed, but it follows the page scroll

Static, the default position
