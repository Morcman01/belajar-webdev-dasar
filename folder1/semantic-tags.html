Semantic tags are struture tags used to increase SEO performance and keep better track of a page layout, they are:

-Header -> used for introductory content

-Nav -> used for navigation bar and links

-Main -> the main content of the webpage

-Section -> contents that are dependent of the main content

-Aside -> side contents that still relates to the mai content

-Article -> contents that are independent of the main content, somewhat similar to section

-Footer -> the closing content
