Flex allows flexible and responsive ui placement, the display: flex; properties is placed in the container's class. flex box has multiple ways to be styled: flex-direction, justify content (x axis), text-align (y-axis), flex wrap (for when there's lots of special-elements), align-content (usually used with flex-wrap) you can also add gaps between elements using column-gap and row-gap. you can also align individual elements using the align-self property, and set the order of each elements using order
