DIVs

<div> or division is a block level container used to separate two block of elements

div is usually used for css styling or JS manipulation, but structurally it can be used to separate html elements

though be careful cause it might get confusing

SPANs

<span> is an inline level container used to separate two elements

span is also used for styling or JS manipulation, but structurally it can be used to separate html elements

this is the first block of text this is the second one
span can be used nested too though be careful cause it might get confusing

DIVs and SPANs are usually used as a way to separate parts of the page, thus allowing it to be identified using id and classes
